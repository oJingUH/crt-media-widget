RETRO-CONTROLLER // PORTABLE - first run
=================================

What this is
------------
A self-contained copy of the RETRO-CONTROLLER desktop widget: a green-phosphor CRT
panel that shows and controls whatever media session Windows is publishing
(Spotify, a browser tab, Media Player - anything that speaks SMTC), plus the
system volume through Core Audio.

It carries its own private copy of CPython in the "python" folder next to this
file. You do NOT need Python installed, and nothing is written into your
Program Files or into the registry. This whole folder is disposable: delete it
and nothing is left behind.

This is the portable zip from the releases page. If you ever need a newer one,
take the current zip from
    https://github.com/oJingUH/retro-controller/releases/latest
extract it the same way, and delete this folder.

Start it (two clicks)
---------------------
    Double-click  RETRO-CONTROLLER.vbs

That is the normal start: no console window, the widget appears in the
bottom-right of the primary screen. The tray icon (a small pixel CRT in the
notification area, behind the hidden-icons chevron the first time) can toggle
always-on-top, click-through and reset the position, and it holds the Quit
item.

    Double-click  RETRO-CONTROLLER.bat

is the troubleshooting start: it keeps a console window open showing the
widget's log. If something misbehaves, run this one and read the console.

To start it automatically with Windows, put a shortcut to RETRO-CONTROLLER.vbs in
your Startup folder (Win+R -> shell:startup).

Requirements
------------
* Windows 10 or 11, 64-bit.
* The Microsoft Edge WebView2 runtime. It is preinstalled on Windows 11; on
  Windows 10 you may already have it from Edge. If it is missing, this build
  says so itself in a dialog box when you start it (do not go looking for a
  blank window). The free "Evergreen Standalone Installer" (x64) is at
      https://developer.microsoft.com/microsoft-edge/webview2/
* .NET Framework 4.8 or newer. Preinstalled on fully updated Windows 10 and
  Windows 11 - and reported by the same startup check if it is missing, with
  the download at
      https://dotnet.microsoft.com/download/dotnet-framework/net48

Nothing else. No Python, no admin rights, no installer. The startup check does
not install anything: it reads two registry keys and tells you what to do.

If it will not start
--------------------
1) Nothing happens at all.  You should have seen a dialog box naming whichever
   of the two requirements above is missing, with the download link in it - the
   silent launcher (RETRO-CONTROLLER.vbs) hides the log completely, which is exactly
   why a missing component is reported in a dialog box instead.

   To see what the check read, open a Command Prompt in this folder and run:

       python\python.exe app.py --preflight

   It prints the raw WebView2 version and .NET Release number it found, exits 0
   when both are present and 3 when one is not.

2) Windows SmartScreen or your antivirus stops it instead.  A silent script
   that starts a python.exe it carries itself is the shape of thing SmartScreen
   and some antivirus products stop to ask about, and a zip you downloaded
   carries the "mark of the web". Click "More info" -> "Run anyway" on the
   SmartScreen prompt, or start the widget with RETRO-CONTROLLER.bat instead (same
   widget, visible console). This build installs nothing, needs no admin rights
   and writes only your window position - but that does not stop the first
   prompt.

3) The window looks the wrong size for a moment, or once it came up at the
   wrong size.  Startup drives the viewport to exactly the target size, and the
   correction is scaled by the display's device pixel ratio (the --debug settle
   lines print it), so display scaling other than 100% is handled. Honest
   limit: it has been measured at 100% scaling only. The loop verifies the
   final size whatever the scaling, and will not remember a size it could not
   reach.

Where it keeps things
---------------------
    %LOCALAPPDATA%\retro-controller\position.json

is the only file it writes: the last window position and size. Delete that
file (or use the tray item "Reset position") to snap the widget back to the
bottom-right corner.

Only one copy can run at a time. If you double-click the launcher again while
the widget is already up, the second copy notices and exits quietly - use the
tray icon of the first one.

Check it by hand (optional)
---------------------------
To prove the bundled runtime can reach Windows' media API, open a Command
Prompt in this folder and run:

    python\python.exe media_selftest.py

It prints a JSON report and exits 0 when every check passes. Note that it
briefly pauses / skips / seeks whatever is currently playing and changes the
system volume, then puts everything back; it reports exactly what it observed.
